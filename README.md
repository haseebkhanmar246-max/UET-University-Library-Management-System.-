# UET-University-Library-Management-System.-

🚀 Project Overview & Vision
The University Library Management System (LMS) is a comprehensive software engineering capstone project engineered to replace outdated manual record-keeping and legacy systems with a streamlined, high-performance digital platform.

Designed specifically to support university students, faculty members, and librarians, this platform centralizes every facet of library administration—from real-time inventory search to automated fine calculations and book reservations.

🎯 What Will This System Do? (Core Features)
The LMS automates and digitizes the entire lifecycle of library resources and user interactions:

Book Cataloging & Inventory Control: Maintains a searchable digital database of all physical and digital academic texts, journals, and reference materials indexed by ISBN, author, title, and category.

Circulation Management (Borrowing & Returns): Digitally processes check-outs and check-ins, automatically applying loan periods based on user roles (students vs. faculty).

Reservation Queueing: Allows members to place holds on currently checked-out books, managing a fair First-In, First-Out (FIFO) waiting list.

Overdue Tracking & Fines: Automatically monitors due dates, flags late items, and calculates accumulated late fees.

Notification Engine: Sends automated alerts and reminders regarding due dates, overdue statuses, and reservation pick-up windows.

🔍 Detailed Project Scope
To ensure project success within academic timelines, the boundaries of the system are clearly defined:

In-Scope (What We Are Building):
User Authentication & Role-Based Access Control: Secure login portals distinguishing between Students, Librarians, and System Administrators.

Search & Discovery Module: Advanced filters allowing users to check book availability instantly.

Transaction Workflows: Complete logic and database state changes for borrowing, returning, renewing, and reserving assets.

Reporting & Analytics: Generating circulation reports, overdue penalty lists, and most-borrowed book statistics for library staff.

Software Engineering Artifacts: Complete requirements specification (SRS), UML diagrams (Class, ERD, Sequence), work breakdown structures, and high-fidelity UI prototypes.

Out-of-Scope (Excluded from Current Phase):
Physical hardware integration (such as RFID scanners, barcode label printers, or biometric gates).

Real-world payment gateway integration (online fine payments will be simulated/mocked).

Mobile application deployment (the system will be developed as a fully responsive web application).
